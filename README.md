## ✨ Overview

This isn't a template portfolio — it's a full **"Now Streaming"** experience. The entire site is themed around a Prime Video–style interface: a boot-up intro animation, a hero laid out like a title poster, projects displayed as browsable "episodes," and a skills row styled like cast & crew credits.

Everything lives in **one HTML file** — no build step, no dependencies, no framework. Your photo and resume are embedded directly as base64, so the file is 100% portable: download it, double-click it, it works.

---

## 🎥 Features

| Section | What it does |
|---|---|
| **Boot Intro** | A Prime Video–style splash animation — light sweep, glow bloom, and your name flaring into view — plays once on load (skippable, respects reduced-motion) |
| **Hero** | "Now Streaming" poster layout with a parallax photo, animated title shimmer, and a movie-poster title card |
| **About Me** | Bio + quick-stat callouts (projects shipped, efficiency gains, students mentored) |
| **Continue Exploring** | Filterable pills (Web Apps / AI & ML / Automation / Achievements) that live-filter the projects row |
| **Skills I Use** | Icon-tile row with a "See more" expandable section for the full stack |
| **Featured Projects** | Horizontally scrollable cards with mock-UI thumbnails, hover glow, and direct links to live demos + source |
| **Work Experience** | Styled as an "Episode Guide" — each accomplishment is an episode with its own stat payoff |
| **Certifications & Education** | Clean bonus-features grid |
| **Extras** | Dark-mode film grain overlay, magnetic button glow, scroll-reveal animations, mobile hamburger menu, back-to-top button, click-to-copy email, and a downloadable embedded resume |

## 🛠 Tech Stack

- **HTML5 / CSS3** — no framework, custom properties for theming
- **Vanilla JavaScript** — IntersectionObserver for scroll reveals, no libraries
- **Fonts** — [Bebas Neue](https://fonts.google.com/specimen/Bebas+Neue), [Inter](https://fonts.google.com/specimen/Inter), [IBM Plex Mono](https://fonts.google.com/specimen/IBM+Plex+Mono) via Google Fonts

No React, no build tools, no `node_modules`. Just one file.

## 🚀 Getting Started

### Run it locally
```bash
git clone https://github.com/Sourav93-subh/<your-repo-name>.git
cd <your-repo-name>
open index.html          # macOS
# or just double-click index.html in Finder
```

### Deploy your own copy (free, via Vercel)
```bash
npm i -g vercel
vercel login
vercel --prod
```
When prompted for a framework preset, choose **"Other"** — there's no build command needed, it's a static file.

Or deploy from the browser: [vercel.com/new](https://vercel.com/new) → import this repo → Framework: **Other** → Deploy.
